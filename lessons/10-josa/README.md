# 10. 조사 표현식

## 배우는 것

- `값을 함수(인자)` 가 `함수(값, 인자)` 라는 규칙
- `정렬한다`, `걸러낸다`, `변환한다`, `축약한다`
- 받침에 맞는 조사 고르기와 이어 쓰기

## 실행

```sh
kingsejong lessons/10-josa/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

## 연습 문제

1. 1부터 10까지에서 3의 배수만 골라 제곱한 합을 조사 표현식 한 줄로 써 보세요.
2. 조사를 받침에 맞지 않게 바꾼 뒤 `kingsejong lint main.ksj` 가 무엇을 알려 주는지 보세요.
