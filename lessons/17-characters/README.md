# 17. 글자 다루기

> 이 레슨은 다음 KingSejong 릴리스(v0.7.0 이후 main)의 기능을 씁니다. v0.7.0 에서는 실행되지 않습니다.

## 배우는 것

- 문자열 인덱스 (`s[i]`, 음수 인덱스)
- 문자열 자르기 (`s[a부터 b까지]`, `미만`)
- 글자와 유니코드 번호 (`문자코드`, `코드문자`)
- 번호 셈으로 대문자 바꾸기, 한글 초성 구하기

## 실행

```sh
kingsejong lessons/17-characters/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

## 연습 문제

1. `대문자로` 를 거꾸로 해서 `소문자로` 함수를 만들어 보세요.
2. 문자열을 뒤집는 함수를 인덱스로 만들어 보세요 (`"세종"` → `"종세"`).
3. 한글 음절의 중성은 `((코드 - 44032) % 588) / 28` 번째 모음입니다. `중성` 함수를 만들어 보세요.
