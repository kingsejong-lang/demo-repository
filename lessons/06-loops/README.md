# 06. 반복문

## 배우는 것

- `N번 반복한다`
- 범위 반복 (`까지`, `미만`)
- 조건 반복 (`반복 (조건)`)
- 거꾸로 세기 (`이상`)
- 반복 끝내기와 건너뛰기 (`중단`, `계속`)

## 실행

```sh
kingsejong lessons/06-loops/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

3. 1부터 차례로 더해 가다가 합이 1000을 처음 넘는 수를 `중단` 으로 찾아보세요.
