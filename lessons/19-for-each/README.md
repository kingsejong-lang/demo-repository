# 19. 요소 반복

> 이 레슨은 다음 KingSejong 릴리스(v0.7.0 이후 main)의 기능을 씁니다. v0.7.0 에서는 실행되지 않습니다.

## 배우는 것

- `컬렉션 각각에 대해 변수로 { }`
- 문자열을 글자 단위로 돌기
- 요소 반복 안의 `중단`, `계속`
- 회차마다 새로 생기는 변수와 클로저

## 실행

```sh
kingsejong lessons/19-for-each/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

## 연습 문제

1. 배열에서 짝수만 모아 새 배열을 만들어 보세요.
2. 영어 문장에 모음 `a e i o u` 가 몇 개 있는지 세어 보세요.
3. 사전의 키 목록(`딕셔너리_키들(사전)`)을 요소 반복으로 돌며 값을 출력해 보세요.
