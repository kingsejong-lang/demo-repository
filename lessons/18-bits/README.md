# 18. 비트 연산

> 이 레슨은 다음 KingSejong 릴리스(v0.7.0 이후 main)의 기능을 씁니다. v0.7.0 에서는 실행되지 않습니다.

## 배우는 것

- 16진수·2진수 리터럴 (`0xFF`, `0b1010`)과 지수 리터럴 (`1e3`, 값은 실수)
- `&` `|` `^` `~`
- 밀기 (`<<`, `>>`)
- 플래그 켜기·끄기·확인하기

## 실행

```sh
kingsejong lessons/18-bits/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

## 연습 문제

1. `n & (n - 1)` 이 0 인지로 2의 거듭제곱인지 확인하는 함수를 만들어 보세요.
2. `이진수` 를 바꿔 16진수 문자열을 만드는 함수를 만들어 보세요.
3. 두 수를 임시 변수 없이 `^` 로 맞바꿔 보세요.
