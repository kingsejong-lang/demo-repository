# 20. 비교 함수로 정렬하기

> 이 레슨은 다음 KingSejong 릴리스(v0.7.0 이후 main)의 기능을 씁니다. v0.7.0 에서는 실행되지 않습니다.

## 배우는 것

- `정렬한다` 와 비교 함수
- 여러 값을 가진 항목을 원하는 기준으로 정렬하기
- 안정 정렬 (같으면 원래 순서)
- `길이(사전)`

## 실행

```sh
kingsejong lessons/20-sorting/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

## 연습 문제

1. 사람들을 이름 순서로 정렬해 보세요. 문자열은 `<` 로 비교할 수 있습니다.
2. 나이가 같으면 이름 순서로 정렬하는 비교 함수를 만들어 보세요.
3. 점수 사전에서 점수가 높은 순서로 이름을 출력해 보세요.
