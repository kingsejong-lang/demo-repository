# 22. 모듈의 비공개 이름

> 이 레슨은 KingSejong v0.8.0 이상이 필요합니다.

## 배우는 것

- 같은 폴더의 파일을 모듈로 가져오기 (`가져오기 "도형"` 은 [`도형.ksj`](도형.ksj))
- `_` 로 시작하는 이름은 그 모듈 안에서만 쓴다. `가져오기` 는 이 이름을 가져가지 않는다.
- 가져오는 쪽에 같은 `_` 이름이 있어도 충돌하지 않는다. 모듈의 함수는 자기 모듈의 `_` 이름을 그대로 쓴다.

## 실행

```sh
kingsejong lessons/22-private-names/main.ksj
```

기대하는 출력은 [`expected.out`](expected.out) 에 있습니다.

## 연습 문제

1. `main.ksj` 끝에 `출력(_원주율)` 을 넣고 실행해 보세요. 모듈의 비공개 이름이라 "정의되지 않은 변수" 오류가 납니다.
2. `도형.ksj` 에 `삼각형_넓이(밑변, 높이)` 를 더하고, `_길이_확인` 을 써서 0 이하의 길이를 막아 보세요.
3. `main.ksj` 의 맨 앞(`가져오기` 보다 위)에 `원_넓이 = 함수(r) { 반환 0 }` 을 넣고 실행해 보세요. 모듈의 공개 함수와 이름이 겹치면 "가져오기 이름 충돌" 오류가 납니다. `_` 로 시작하는 이름은 겹쳐도 괜찮은 이유를 생각해 보세요.
